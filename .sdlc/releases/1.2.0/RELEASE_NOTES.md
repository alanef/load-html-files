# Release 1.2.0

**Date:** 2026-10-23
**Previous:** v1.1.1

## Highlights

Updates the bundled opt-in library from 1.0.1 to 1.3.3, makes deleting the plugin keep your HTML files, and clears
the Plugin Check errors (Tested up to 7.1, a direct-access guard).

## What's New

### Features
- A dismissable setup notice that links to the opt-in screen, where you can opt in or skip.

### Fixes
- Deleting the plugin removes its settings and opt-in choice. HTML files, their categories and uploaded files are kept.
- Security: the unused control/autoloader.php refuses direct access.

### Improvements
- The opt-in screen is shown again from the plugin's settings page until you click Allow or Skip.
- Opt-ins go to the current mailing service.
- The advert on the settings page is gone.
- Tested up to WordPress 7.1.

## Breaking Changes

None. Stored settings and opt-in choices are kept.

## Migration Guide

None.
